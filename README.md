# 锁契 · PACT

**Padlock Authorization & Covenant Toolkit** · 挂锁授权与契约工具集

Bondage Club 中文挂锁插件。功能与狗锁（DOGS）兼容，界面全中文，由中文社区自行维护与适配，不再等待外国作者更新。

## 名字的含义

| 字母 | 英文 | 中文 | 含义 |
|---|---|---|---|
| **P** | Padlock | 挂锁 | 核心功能 |
| **A** | Authorization | 授权 | 钥匙权限、锁具管理、远程授权 |
| **C** | Covenant | 契约 | 双方建立的约定与锁定关系 |
| **T** | Toolkit | 工具集 | 为日后加入其他 BC 功能留出扩展空间 |

## 功能

- **契锁**：佩戴者自己无法取下的挂锁，可配置钥匙持有人、最低身份、成员编号、备注、定时解锁、密码、防作弊
- **配置方案**：保存并批量应用锁的设置
- **远程控制**：被授权者可远程改变外观（后续版本）
- **完全兼容狗锁协议**：能识别并处理别人身上的狗锁，反之亦然

## 兼容性与上锁说明

锁契和狗锁（DOGS）使用同一套底层协议，因此互通。给不同的人上锁，效果不同：

| 对方的情况 | 能否上锁 | 锁会得到守护吗 |
|---|---|---|
| 装了锁契，或装了可用的新版狗锁 | ✅ 能 | ✅ 会。对方能识别、管理，掉线后自动恢复 |
| 装了**已被作者停用的原版狗锁** | ✅ 能 | ⚠️ 不会。对方插件的锁模块被关闭，锁解开后不会被自动恢复 |
| **完全没装**任何锁插件 | ❌ 不能 | — 上锁按钮会被拦，物品栏也不显示锁，无法上锁 |

**说明**：

- 插件通过进房间时自动同步的配置来识别"对方是否装了插件"。没装插件的玩家无法被上锁，这是刻意设计，避免出现无人管理的锁。
- 原版狗锁目前已停用（作者注释掉了锁模块）。它虽然还在同步配置、能被识别，但**不会帮你守护锁**。如果想让锁稳定生效，建议对方改装锁契，或等待原版恢复。
- 锁契无法从外部可靠判断对方插件的锁模块是否真的在运行，因此不会自动阻止给停用版上锁——请根据上述表格自行判断。

## 安装

### Tampermonkey（推荐）

一键安装：[点此安装 锁契 · PACT](https://raw.githubusercontent.com/heitaoplay/PACT/main/pact.user.js)

安装后油猴会自动检查更新，以后发新版无需手动重装。

###  bookmarks（备用）

把 `pact.user.js` 的内容存成浏览器书签即可。

## 开发

```bash
pnpm install       # 安装依赖
pnpm build         # 生产构建
pnpm build:dev     # 开发构建
pnpm dev           # 本地开发服务器 + 自动安装加载器
```
